# 地铁线路图分形维度分析（QGIS 插件）

## 安装

本插件无额外 Python 包依赖，使用 QGIS 自带的 PyQGIS 与 Qt。建议在插件管理器中通过“从 ZIP 安装”安装 `qgis_fractal_plugin.zip`。若手动安装，将 `qgis_fractal_plugin` 文件夹复制到 QGIS 当前用户配置的 `python/plugins` 目录，然后在插件管理器中启用。

## 使用

1. 在 QGIS 中加载地铁线路图，选中要分析的图层。
2. 打开“地铁线路图分析 → 地铁线路图分形维度”，默认会选中活动图层。
3. 选择输出目录和渲染分辨率；使用 Otsu 自动阈值，或切换到手动阈值。
4. 点击“开始分析”。在“初始 RGB 图”“灰度图”“二值图”标签页检查各阶段结果；“箱计数与拟合”页显示拟合图、各尺度箱数、分形维度与 R²。

## 处理方式

- 插件使用所选单个图层的范围，构造与坐标轴平行的最小外接正方形，并用该图层在 QGIS 中的符号样式渲染为正方形画布。
- 渲染图像先合成到白色背景，再转换到 RGB 和 8 位灰度。透明像素因此按白色背景处理。
- 二值图沿用原代码的判定方式：灰度值小于阈值的像素成为白色前景（线路）；其他像素为黑色背景。
- 从 2 像素箱宽开始按 2 倍递增至 1024 像素，统计与线路前景相交的箱数。采用 `log2(N)` 对 `log2(箱宽)` 的线性回归，分形维度为拟合斜率的相反数，报告 R²。
- 边缘不满一个箱宽的像素块也参与计数。分辨率不必是 2 的幂。

## 输出

- `initial_rgb.png`：单图层正方形渲染图。
- `grayscale.png`：8 位灰度图。
- `binary.png`：白色线路前景的二值图。
- `box_counts.csv`：箱宽、非空箱数及其 log2 值。
- `fractal_dimension.txt`：图层、CRS、阈值、拟合方程、维度和 R²。

结果反映的是当前图层渲染样式和所选分辨率下的栅格图像，不等同于直接对原始矢量几何计算的分形维数。线宽、标签、符号和阈值均可能影响结果。
